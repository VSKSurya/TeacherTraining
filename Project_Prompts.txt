Toggle Visibility

Display the Teacher / Student toggle in the topbar only when the user logs in through ERNET.

Teacher Selection

The selected Teacher mode must remain active while navigating between pages.

Global Data Synchronization

The toggle must work globally across the entire ERNET portal.
Whenever the selection changes, all relevant page data must refresh automatically based on the selected mode.
The user should not need to refresh the browser manually.
Ensure that Student and Teacher data are not mixed.

UI/UX Requirements

Highlight the currently selected option.
Maintain the selected mode during navigation and page reloads.

Expected Result:
