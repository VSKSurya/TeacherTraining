04 Not run

  • The project has no npm test script or configured automated test framework, so there was no automated case suite to execute.
  • Most cases in the test plan require role-by-role sessions, controlled mutations, dedicated fixtures, import files, or configured backend services. They were not exercised.
  • VAPT page-level cases SEC-001 through SEC-016 and code-level CODE-* cases were not performed as a full assessment. Only the limited route-gate observation in RUN-010 was checked.
  • Recovery OTP success, expiry, replay, enumeration, and throttling need a controlled recovery service. None was configured.
  • Server-side access control, API authorization, deployed TLS and response headers, rate limiting, and production behavior cannot be established from this local browser run.
  • Result type visual alignment could not be confirmed reliably at the available browser viewport; this item remains unverified.

05 Build note

Performance advisory

Vite reported that the generated JavaScript bundle is larger than its 500 kB advisory threshold. The largest generated JavaScript asset was approximately 1,021.58 kB. This was a warning; the build succeeded. Code splitting or lazy-loading report routes may reduce the initial bundle size.

06 Overall assessment

The build and nine listed local checks passed. No failure was observed in those checks. This result is not a VAPT clearance and does not supersede the static security finding documented in the test plan: client-side demo authentication and route checks are not a trusted security boundary for real or shared records.

Complete the marked security cases against a properly configured, authorized staging environment before treating security as verified.
